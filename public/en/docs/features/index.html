    Features & Use Cases#

    Core features#

    • Local transcription without cloud dependency.
    • Multilingual models (60+ languages).
    • Speaker identification for speaker attribution.
    • Built-in editor for review and corrections.
    • Open-source stack based on Whisper, faster-whisper, and pyannote.

    Typical scenarios#

    • Qualitative interviews in research and teaching
    • Journalism workflows
    • Project meetings, workshops, field notes
