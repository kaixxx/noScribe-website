    Erste Schritte#

    Download#

    Die offiziellen Builds finden Sie auf GitHub Releases. Wählen Sie das passende Paket für Ihr Betriebssystem (Windows, macOS, Linux).

    Zu den Releases

    Installation & Start#

    1. Laden Sie das Release für Ihr System herunter.
    2. Installieren oder starten Sie die App entsprechend der Paketform (z. B. Installer/ZIP).
    3. Öffnen Sie noScribe und importieren Sie eine Audio-/Video-Datei.

    Erste Transkription#

    • Wählen Sie Sprache und Modell.
    • Starten Sie die Transkription.
    • Prüfen Sie das Ergebnis im integrierten Editor und korrigieren Sie bei Bedarf.
    Die Modell-Downloads sind groß (mehrere GB). Planen Sie Zeit und Speicherplatz ein.

    Bekannte Hinweise & Grenzen#

    • Transkription kann langsam sein: Eine Stunde Audio kann bis zu ca. drei Stunden Rechenzeit benötigen.
    • Starke Nebengeräusche reduzieren die Qualität.
    • Ein Korrektur-Review ist empfehlenswert.
