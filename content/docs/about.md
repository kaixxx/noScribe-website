# Über noScribe

noScribe ist ein Open-Source-Projekt von **Kai Dröge**. Ziel ist eine datenschutzfreundliche, lokal ausführbare Transkriptionssoftware für Interviews, Forschung und journalistische Arbeit.

- **Autor:** Kai Dröge ([GitHub-Profil](https://github.com/kaixxx))
- **Code-Repository:** https://github.com/kaixxx/noScribe
- **Lizenz:** GPL-3.0

## Abgrenzung

Es existieren kommerzielle Drittangebote unter ähnlichem Namen, die nicht mit diesem Open-Source-Projekt verbunden sind.
