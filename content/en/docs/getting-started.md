# Getting Started

## Download

Official builds are published on GitHub Releases. Choose the package for your operating system (Windows, macOS, Linux).

{{< button href="https://github.com/kaixxx/noScribe/releases" >}}Open Releases{{< /button >}}

## Install & Launch

1. Download the release for your system.
2. Install or unpack the app (depending on the package type).
3. Open noScribe and import an audio/video file.

## First transcription

- Select language and model.
- Start transcription.
- Review and correct the result in the built-in editor.

{{< hint >}}
Model downloads can be large (multiple GB). Plan time and disk space.
{{< /hint >}}

## Known notes & limits

- Transcription can be slow: one hour of audio can take up to ~three hours of processing time.
- Heavy background noise reduces quality.
- A manual review pass is recommended.
