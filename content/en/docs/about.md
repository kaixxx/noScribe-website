# About noScribe

noScribe is an open-source project by **Kai Dröge**. The goal is a privacy-friendly, local transcription app for interviews, research, and journalism.

- **Author:** Kai Dröge ([GitHub profile](https://github.com/kaixxx))
- **Code repository:** https://github.com/kaixxx/noScribe
- **License:** GPL-3.0

## Name clarification

Commercial third-party products with a similar name exist and are not affiliated with this open-source project.
