### Hébergement (GitHub Pages)

Ce site est fourni en tant que site statique via GitHub Pages. Lors de l’accès, les adresses IP des visiteurs sont enregistrées et stockées par GitHub pour des raisons de sécurité. Le destinataire des données est l’hébergeur GitHub (GitHub, Inc.). La base juridique est l’art. 6(1)(f) RGPD (intérêt légitime à un fonctionnement sûr et fiable du site).

### Contact

Si vous me contactez par e‑mail, les données transmises seront traitées pour gérer votre demande. La base juridique est l’art. 6(1)(f) RGPD. Les données seront supprimées une fois votre demande entièrement traitée et si aucune obligation légale de conservation ne s’applique.

### Durée de conservation

À moins qu’une durée plus spécifique ne soit indiquée dans cette politique, les données personnelles seront supprimées dès qu’elles ne sont plus nécessaires aux finalités indiquées.

### Droits des personnes concernées

Vous avez le droit d’accès, de rectification, d’effacement, de limitation du traitement, de portabilité des données et d’opposition au traitement de vos données personnelles. Vous avez également le droit de déposer une plainte auprès d’une autorité de contrôle de la protection des données.
